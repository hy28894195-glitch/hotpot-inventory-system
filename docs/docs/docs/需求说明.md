# 火锅店报货、库存及采购管理系统

## 一、基本信息
- 门店数量：1家
- 门店端：手机网页
- 库房端：手机网页
- 系统语言：简体中文

## 二、业务流程
1. 门店员工选择商品并填写报货数量。
2. 门店提交报货单，系统保存提交时间和订单编号。
3. 库房查看报货单，审核每种商品的需求数量。
4. 库房填写实际出库数量并确认出库。
5. 系统根据库存和出库数量识别缺货商品。
6. 库房将缺货商品整理为采购单，记录采购数量和采购状态。

## 三、商品资料
每个商品包含：商品编码、商品名称、分类、规格、单位、商品图片、安全库存、当前库存、供应商。

## 四、报货单
包含：订单编号、门店、提交时间、商品名称、报货数量、单位、审核数量、实际出库数量、订单状态。

## 五、库存管理
记录商品入库、出库、采购入库、库存调整及操作时间。库存变化必须保留记录。

## 六、采购管理
缺货商品进入采购清单，记录采购数量、供应商、下单时间、到货数量和采购状态。

## 七、账号权限
- 门店账号：只能提交和查看本门店报货单。
- 库房账号：可以审核报货、管理库存、确认出库和处理采购。

## 八、其他要求
- 支持手机操作。
- 支持商品搜索和商品图片。
- 支持商品资料表格导入。
- 支持安全库存预警。
- 重要操作保留日志。
- 需要登录验证、数据库备份和权限保护。
